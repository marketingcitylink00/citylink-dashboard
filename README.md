### 📂 ไฟล์ภายในโฟลเดอร์นี้
- **`index.html`** : ไฟล์ Dashboard หลักฉบับสมบูรณ์ (ซิงค์อัตโนมัติจาก `Marketing_Dashboard_2569.html`)
- **`DASHBOARD_LIVE_URL.txt`** : ไฟล์ข้อความบันทึกลิงก์ออนไลน์
- **`CityLink_Dashboard_Online.url`** : ชอร์ตคัตสำหรับดับเบิลคลิกเปิดหน้าเว็บออนไลน์ทันทีบน Windows
- **`august_daily_dashboard.html`** : ข้อมูลสถิติรายวันเดือนสิงหาคม
- **`citylink_logo.png`** : โลโก้โครงการ City Link

### 🔄 การอัปเดตข้อมูลขึ้นระบบออนไลน์
เมื่อมีการอัปเดตข้อมูลในโฟลเดอร์ `agents/` ให้รันสคริปต์:
```powershell
powershell -ExecutionPolicy Bypass -File update_dashboard.ps1
```
ระบบจะอัปเดตไฟล์ในโฟลเดอร์นี้และ Push ขึ้น GitHub Pages ให้อัตโนมัติทันที
